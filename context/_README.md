# Папка контекстных материалов

Сюда клади справочные файлы (`.md` или `.txt`), на которые агент должен опираться
при анализе требований: **глоссарий, стандарты оформления, шаблоны, примеры готовых документов**.

## Как это работает
- Всё, что лежит в этой папке, автоматически попадает в системный промпт агента
  (кэшируется — на повторных запросах почти бесплатно по токенам).
- Агента попросили **ссылаться на источник по имени файла**, когда он использует материал
  (например: «согласно `glossary.md`…»).

## Правила
- Держи файлы **лёгкими**: глоссарий / стандарты / шаблоны. Тяжёлые документы лучше
  прикреплять **вложением к конкретному сообщению**, а не держать тут постоянно
  (иначе они шлются в каждом запросе и едят токены).
- Чтобы временно отключить файл, не удаляя, — переименуй, добавив `_` в начало
  (например, `_draft.md`). Файлы на `_` и `.` в контекст не подгружаются.
- После добавления/удаления файла сделай **Push** — Render пересоберётся и подхватит изменения.

Сам этот файл (`_README.md`) в контекст агента не попадает.
